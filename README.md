# Sistema de Gestión de Stock - Clínica

Aplicación de escritorio desarrollada en Python y Flet para el control de inventario médico, ingresos y egresos de insumos.

## Instalación

1. Asegurate de tener Python 3 instalado.
2. Abrí la terminal en la carpeta del proyecto.
3. (Opcional pero recomendado) Creá un entorno virtual:
   `python -m venv venv`
   `venv\Scripts\activate` (en Windows)
4. Instalá las dependencias exactas:
   `pip install -r requirements.txt`

## Uso y Ejecución

Para iniciar la aplicación, asegurate de estar en la raíz del proyecto y ejecutá:
`python main.py`

*Nota: La base de datos SQLite (`clinica.db`) se generará automáticamente en el primer arranque.*
