# Gestión de Inventario Clínico

Aplicación de escritorio desarrollada en Python y Flet para el control de inventario médico, ingresos y egresos de insumos, y gestión de personal autorizado.

## Instalación

1. Asegurate de tener Python 3 instalado en tu sistema.
2. Abrí una terminal en la carpeta raíz del proyecto.
3. Instalá las dependencias exactas ejecutando:
   `pip install -r requirements.txt`

## Uso y Ejecución

Para iniciar la aplicación, asegurate de estar en la raíz del proyecto y ejecutá:
`python main.py`

*Nota: La base de datos SQLite (`clinica.db`) se generará automáticamente en el primer arranque si no existe.*
